# 🌊 Rising Tide Ark

A Roblox game in the style of *Build a Boat for Treasure*: build an ark block by block on your dock, lead animals aboard **in pairs**, then survive the flood and the storm.

## Round loop
1. **Intermission (15s)**: water drains, your saved ark is rebuilt, animals spawn on the island.
2. **Build (2:30)**: place blocks on your dock and walk animals to your ark. Rare animals live higher up the mountain.
3. **Flood (3:00)**: arks are unanchored and the water rises for real (Terrain water, so boats float with physics). Animals flee uphill. Climb your ark's ladder if you're in the water.
4. **Voyage (1:15)**: storm! Lightning damages blocks and waves rock your ark. Lose too many blocks and it breaks apart.
5. **Results**: every male + female pair of a species still aboard earns coins. New species are added to your Sanctuary collection.

## Controls
| Action | PC | Mobile |
|---|---|---|
| Build mode | B or 🔨 button | 🔨 button |
| Pick block | 1 to 5 | block buttons |
| Place | click | tap dock/ark |
| Rotate | R | ↻ Turn |
| Delete | X, then click | 🗑 Delete, then tap |
| Lead animal | E near it | tap the prompt |

## Blocks
Wood (basic), Plank (thin floor), Hull (tough, 8 HP), Stable (+2 animal slots), Sail. Giraffes and Elephants take 2 slots.

## Project layout
```
src/shared   -> ReplicatedStorage.Shared   (Config, Blocks, Grid)
src/server   -> ServerScriptService.Server (Main, Map, Water, Data, Build, Animals, Round)
src/client   -> StarterPlayerScripts.Client (BuildController, HUD)
```
All balancing numbers are in `src/shared/Config.lua`.

## Setup with Rojo
1. Install [Rojo](https://rojo.space) (VS Code extension + Roblox Studio plugin).
2. Open this folder in VS Code, start Rojo (`rojo serve`).
3. In Studio: open an empty Baseplate, **delete the Baseplate part**, then connect with the Rojo plugin.
4. Game Settings → Security → turn on **Enable Studio Access to API Services** (for saving).
5. Press Play. The island, docks and water are generated by code.
